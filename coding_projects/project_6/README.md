# Linear Equation Solver (C++)

## Overview
This project solves systems of linear equations using Gaussian elimination and also integrates MATLAB and Python for verification.

## Implementations
- C++ version in /cpp

## How It Works
- Stores matrix A and vector B from input
- Performs Gaussian elimination to solve AX = B
- Supports:
  - Ascending and descending sorting of solutions
  - External solving via MATLAB and Python scripts
  - Matrix inversion using inherited methods

## Key Concepts
- Gaussian elimination
- Numerical methods
- Matrix operations
- Interfacing with external tools (MATLAB/Python)
