# Advanced Course System with Operator Overloading (C++ & Python)

## Overview
This project introduces operator overloading to make the course system more intuitive and powerful.

It allows operations like comparing courses and modifying student data using operators.

## Implementations
- C++ version in /cpp
- Python version in /python

## How It Works
- Extends Project 3
- Adds overloaded operators to simplify operations on course objects

Key features:
- `>` operator → Compare number of students
- `+=` operator → Merge students from another course
- `-=` operator → Remove a student by ID
- `INSERT_STUDENT` → Add a new student
- `P4_SORT` → Sort students using inherited methods

## Key Concepts
- Operator overloading
- Advanced object-oriented design
- Code reusability through inheritance
