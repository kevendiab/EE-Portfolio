# Student Course System (C++ & Python)

## Overview
This project implements a basic course management system that reads student data from a file and stores student IDs and PINs.

It demonstrates how to structure data using classes and how to handle file input/output in both C++ and Python.

## Implementations
- C++ version in /cpp
- Python version in /python

## How It Works
- Reads student IDs and PINs from `studentInfo.txt`
- Stores them in arrays (C++) or lists (Python)
- Provides a method (`P0_LIST`) to display:
  - Basic course info
  - Student IDs
  - Error handling for invalid inputs

## Key Concepts
- File I/O (reading from files)
- Object-oriented programming (classes, constructors)
- Arrays vs Python lists
- Basic input validation

## What I Learned
- How to structure a class to manage data
- Differences between C++ arrays and Python lists
- Handling file input and debugging data flow
