# Course Management System with Grades (C++ & Python)

## Overview
This project extends a basic course management system by introducing student exam grades and additional functionality such as searching and grade analysis.

It builds on the base system by incorporating more complex data structures and operations.

## Implementations
- C++ version in /cpp
- Python version in /python

## How It Works
- Inherits from the base course system (Project 0)
- Reads student IDs, PINs, and exam grades from input files
- Stores grades in a 2D structure (array in C++, list of lists in Python)

The system provides:
- `P1_LIST` → Displays course information or full student data
- `P1_MIN` → Finds the student with the lowest grade in a given exam
- `P1_FIND` → Searches for a student using ID and PIN

## Key Concepts
- Inheritance (extending a base class)
- Multi-dimensional data storage
- Searching and traversal algorithms
- Input validation and error handling

## What I Learned
- How to extend functionality using inheritance
- Managing structured data like grades across multiple students
- Implementing search and analysis functions in both C++ and Python
