# Course Database with Student Management (C++ & Python)

## Overview
This project expands the system into a more complete student database by including names and allowing dynamic updates such as adding and modifying student records.

## Implementations
- C++ version in /cpp
- Python version in /python

## How It Works
- Extends Project 2
- Adds first and last names for each student
- Reads data from an additional input file

Key features:
- `P3_LIST_ALL` → Displays all students with names and grades
- `P3_ALPHABETIZE` → Sorts students by last name
- `P3_INSERT` → Adds a new student if they don’t already exist
- `P3_UPDATE` → Updates a student’s exam grade

## Key Concepts
- String handling and sorting
- Dynamic data updates
- Database-like operations (insert/update)
- Maintaining consistency across multiple data arrays

- Managing more complex datasets
- Implementing real-world operations like adding and updating records
