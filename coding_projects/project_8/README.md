# Numerical Differentiation and Integration (C++)

## Overview
This project approximates derivatives and integrals of functions using numerical methods.

## Implementations
- C++ version in /cpp

## How It Works
- Parses function type (sin/cos)
- Evaluates function values over an interval
- Computes:
  - Derivatives using finite differences
  - Integrals using numerical summation

Also detects:
- Minimum and maximum points

## Key Concepts
- Numerical differentiation
- Numerical integration
- Function approximation
