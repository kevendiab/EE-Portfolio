# Matrix Operations and Linear Algebra System (C++)

## Overview
This project implements a matrix class that supports a variety of mathematical operations, including matrix arithmetic and inversion.

## Implementations
- C++ version in /cpp

## How It Works
- Defines a matrix class with dynamic dimensions
- Supports operations such as:
  - Addition
  - Multiplication
  - Scalar operations
  - Matrix inversion

- Reads matrix data from input files
- Uses inheritance for matrix inversion functionality

## Key Concepts
- 2D arrays
- Matrix algebra
- Operator overloading
- File-based data input
