# Least Squares Curve Fitting (C++)

## Overview
This project performs linear regression using least squares to fit a line to a set of data points.

## Implementations
- C++ version in /cpp

## How It Works
- Reads (x, y) data points from a file
- Computes:
  - Slope
  - Intercept
- Uses a linear solver to calculate best-fit line
- Calculates total squared error

Also supports:
- MATLAB implementation
- Python implementation

## Key Concepts
- Least squares method
- Linear regression
- Error analysis
