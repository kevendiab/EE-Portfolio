# Course Reporting and Data Processing System (C++ & Python)

## Overview
This project builds on the previous system by adding reporting, sorting, and advanced grade analysis features.

It focuses on processing student data and generating meaningful outputs.

## Implementations
- C++ version in /cpp
- Python version in /python

## How It Works
- Extends Project 1
- Adds functionality for generating reports and analyzing student performance

Main features include:
- `P2_REPORT` → Displays either full course info or a specific student’s grade
- `P2_SORT` → Sorts students based on their IDs
- `P2_MINMAX` → Finds minimum or maximum grades for a given exam

## Key Concepts
- Sorting algorithms
- Data restructuring
- Conditional logic for reporting systems
- Multi-level inheritance

## What I Learned
- How to organize larger systems with multiple features
- Implementing sorting and reporting logic
- Handling more complex data flows across functions
