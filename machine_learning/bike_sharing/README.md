# Bike Sharing Prediction Model

## Overview

This project focuses on predicting bike sharing demand using machine learning.

The goal was to understand how different variables affect usage and how models can be used for prediction.

## What I Did

* Worked with real-world bike sharing data
* Built a predictive model
* Analyzed how different inputs impact the output

## Concepts Used

* Regression modeling
* Data preprocessing
* Feature relationships
* Model evaluation
