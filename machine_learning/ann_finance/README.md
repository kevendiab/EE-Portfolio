# ANN Finance Model

## Overview

This project uses an Artificial Neural Network (ANN) to model and analyze financial data.

The goal was to understand how neural networks learn patterns from numerical data and how they can be used for prediction.

## What I Did

* Built and trained a neural network model in Python
* Worked with financial data as input
* Evaluated model performance and behavior

## Concepts Used

* Artificial Neural Networks
* Forward propagation
* Backpropagation
* Model training and evaluation
